# NORD GARAGE

Portfolio/demo project многостраничного сайта специализированного автосервиса европейских автомобилей. Проект демонстрирует тёмную editorial-дизайн-систему, адаптивную вёрстку и статически генерируемые страницы услуг.

> Репозиторий не утверждает существование реального действующего автосервиса NORD GARAGE и не является официальным сайтом компании.

## Стек

- Next.js 16
- React
- TypeScript
- Tailwind CSS

## Страницы

- `/` — главная страница
- `/about` — о проекте сервиса
- `/contacts` — контакты
- `/works` — визуальная галерея
- `/services/*` — страницы направлений обслуживания и ремонта

## Запуск и проверки

```bash
npm run dev
npm run lint
./node_modules/.bin/tsc --noEmit --incremental false
npm run build -- --webpack
npm run start
```

## Демонстрационные данные

Адрес, основной телефон, email, URL сайта и график работы используются как portfolio/demo data для полноты макета. WhatsApp и Telegram могут вести на рабочие пользовательские каналы.

Перед публикацией в качестве сайта реального бизнеса демонстрационные данные необходимо заменить подтверждённой информацией.
