# NORD GARAGE

Многостраничный сайт специализированного автосервиса европейских автомобилей, разработанный как portfolio/demo-проект.

Проект демонстрирует современный премиальный интерфейс, адаптивную вёрстку, переиспользуемую дизайн-систему, отдельные страницы услуг и подготовленную production-конфигурацию.

> NORD GARAGE является portfolio/demo-проектом и не утверждает существование реального действующего автосервиса.

## О проекте

Концепция сайта создана для специализированного автосервиса, ориентированного на обслуживание автомобилей BMW, Mercedes-Benz, Audi и Volkswagen.

Визуальная система построена вокруг тёмной графитовой палитры, крупной editorial-типографики, автомобильной фотографии и сдержанных интерактивных эффектов. Интерфейс адаптирован для мобильных устройств, планшетов и desktop-экранов.

## Возможности

В проекте реализованы:

- адаптивная многостраничная структура;
- главная страница с ключевыми направлениями сервиса;
- отдельные страницы услуг;
- страница «О нас»;
- страница контактов и способов связи;
- страница «Наши работы» с адаптивной галереей;
- динамический маршрут и статическая генерация страниц услуг;
- централизованные конфигурации услуг, контактов и галереи;
- адаптивная навигация;
- брендированная страница 404;
- оптимизированная работа с изображениями через `next/image`;
- SEO metadata, sitemap и robots;
- Open Graph-изображение и брендированная иконка;
- production security headers;
- поддержка `prefers-reduced-motion`.

## Страницы

### Основные

- `/` — главная страница;
- `/about` — информация о концепции сервиса;
- `/contacts` — контакты и способы связи;
- `/works` — визуальная галерея.

### Услуги

- `/services/maintenance` — техническое обслуживание;
- `/services/diagnostics` — компьютерная диагностика;
- `/services/suspension` — ремонт подвески;
- `/services/brakes` — тормозная система;
- `/services/engine-repair` — ремонт двигателя;
- `/services/transmission-repair` — ремонт коробки передач.

### Служебные маршруты

- `/robots.txt`;
- `/sitemap.xml`;
- `/opengraph-image`;
- `/icon.svg`.

## Структура проекта

```text
app/
├── about/                 # Страница «О нас»
├── contacts/              # Страница контактов
├── services/[slug]/       # Динамические страницы услуг
├── works/                 # Страница «Наши работы»
├── globals.css            # Дизайн-токены и глобальные стили
├── layout.tsx             # Корневой layout и metadata
├── not-found.tsx          # Брендированная страница 404
├── opengraph-image.tsx    # Open Graph-изображение
├── robots.ts              # Правила индексации
└── sitemap.ts             # Карта сайта

components/
├── layout/                # Header, Footer и навигация
├── sections/              # Секции главной страницы
├── ui/                    # Базовые UI-компоненты
└── works/                 # Компоненты галереи

config/
├── contact.ts             # Контактные данные и ссылки
├── services.ts            # Данные и контент услуг
└── works.ts               # Конфигурация изображений галереи

public/
└── images/                # Локальные изображения проекта
```

## Локальный запуск

Установите зависимости:

```bash
npm install
```

Запустите development-сервер:

```bash
npm run dev
```

Проект будет доступен по адресу:

```text
http://localhost:3000
```

## Проверка проекта

Проверка ESLint:

```bash
npm run lint
```

Проверка TypeScript:

```bash
./node_modules/.bin/tsc --noEmit --incremental false
```

Production-сборка через Webpack:

```bash
npm run build -- --webpack
```

Запуск собранного приложения:

```bash
npm run start
```

## Production

Опубликованная версия:

[https://nord-garage.vercel.app](https://nord-garage.vercel.app)

Deployment выполняется через Vercel из ветки `main` GitHub-репозитория. Изменения, отправленные в production-ветку, автоматически запускают новую сборку и публикацию проекта.

## SEO

В проекте настроены:

- общие и уникальные metadata страниц;
- шаблон заголовков;
- production `metadataBase`;
- canonical URL;
- Open Graph metadata;
- Twitter Card metadata;
- Open Graph-изображение;
- русская локаль документа;
- `robots.txt`;
- `sitemap.xml`;
- индивидуальные metadata для страниц услуг.

Проект не использует неподтверждённые рейтинги, отзывы или сведения о реальном бизнесе.

## Безопасность

Для production-маршрутов настроены и проверены следующие HTTP response headers:

- `X-Content-Type-Options: nosniff`;
- `Referrer-Policy: strict-origin-when-cross-origin`;
- `X-Frame-Options: DENY`;
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`.

## Демонстрационные данные

Адрес, основной телефон, email, отображаемый URL сайта и график работы используются как демонстрационные данные для полноты макета.

Перед применением проекта для реального бизнеса эти данные необходимо заменить подтверждённой информацией.

## Статус проекта

**Production / стабильная portfolio-версия**

Проект опубликован на Vercel и прошёл проверку production-сборки, маршрутов, адаптивности, SEO-конфигурации и HTTP security headers.

Репозиторий предназначен для демонстрации дизайна, frontend-разработки и архитектуры многостраничного сайта. Он не является официальным сайтом действующего автосервиса NORD GARAGE.
